# Learning Folder

Step-by-step learning material for the tools used in this project. Each tool has its own
folder with numbered lessons — **theory first, then hands-on**, in order.

## Tracks

| Track | Status | Folder |
|---|---|---|
| Jenkins (CI) | 🟢 in progress | [`jenkins/`](./jenkins/) |
| Docker | ⚪ planned | `docker/` |
| Kubernetes | ⚪ planned | `kubernetes/` |
| Istio (service mesh) | ⚪ planned | `istio/` |
| AWS EKS | ⚪ planned | `eks/` |

## How to use this

1. Open a track folder.
2. Read lessons **in number order** (`01-...`, `02-...`).
3. Each lesson ends with a **"Do this"** section — actually do it before moving on.
4. Tie it back to the real project (`../EXECUTION_PLAN.md`) as you go.

> Start here → [`jenkins/01-theory.md`](./jenkins/01-theory.md)
