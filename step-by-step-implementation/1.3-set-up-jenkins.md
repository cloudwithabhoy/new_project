# 02 — Set up Jenkins + Docker (the CI engine)

## Goal
Install Jenkins on the EC2 instance, give it Docker so it can build images, and configure one Pipeline job
per microservice that builds the image and pushes it to **ECR**. **Deploys stay manual** (`kubectl`) —
Jenkins only builds + pushes.

## Why
- Jenkins is our CI server (Phase 1). Each job builds its service's image and pushes
  `ecom-repo:<service>-<git-sha>`.
- Docker on the same host lets Jenkins build images directly — no remote build infrastructure.

## Prerequisites
- The t3.medium instance from [`01-setup-ec2.md`](./1.2-setup-ec2) (running).
- Java 17/21 (Jenkins requirement).

## Steps

### 1. Install Java
```bash
sudo apt install fontconfig openjdk-21-jre
java -version
```

### 2. Install Jenkins (official apt repo)
```bash
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc \
  https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc]" \
  https://pkg.jenkins.io/debian-stable binary/ | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null
sudo apt update
sudo apt install jenkins
sudo systemctl enable jenkins     # start on boot
systemctl status jenkins          # confirm "active (running)"
```
Jenkins now listens on **:8080**.

### 3. Unlock the UI + install plugins
```bash
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```
Open `http://<public-ip>:8080`, paste the password, install suggested plugins, create the admin user.
Then add these (Manage Jenkins → Plugins → Available):
- **Docker Pipeline** — `docker.build` / `docker.withRegistry`
- **Amazon ECR** — the `ecr:<region>:<credId>` login helper
- **AWS Credentials** — provides the "AWS Credentials" credential *kind* (Amazon ECR needs it)
- **GitHub** — the `/github-webhook/` push trigger
- **Job DSL** — the seed job that generates all 6 pipeline jobs

### 4. Install Docker (the build engine)
```bash
sudo apt install docker.io
```

### 5. Give Jenkins (and you) Docker access
Builds run as the **`jenkins`** user, which must be in the `docker` group:
```bash
sudo usermod -aG docker jenkins    # add jenkins to docker group
sudo systemctl restart jenkins     # RESTART so the running process picks up the group
sudo -u jenkins docker ps          # prove jenkins can talk to docker

# (optional) let your SSH user use docker without sudo:
sudo usermod -aG docker ubuntu
newgrp docker                      # apply in the current shell (or re-login)
```
> The **restart** is essential — a running process keeps the groups it had at *start*. (This is also
> why docker access can break after a reboot: re-run `systemctl restart jenkins`.)

### 6. Add the AWS credential for ECR (UI)
Manage Jenkins → Credentials → System → Global → Add Credentials:
- **Kind:** AWS Credentials
- **ID:** `aws-ecr`  ← must match the Jenkinsfile
- **Access Key ID / Secret:** the `eks-user` keys (must have ECR push perms — attach
  `AmazonEC2ContainerRegistryPowerUser`)

### 7. Create the pipeline jobs (one per service) via the seed job
We use **one Pipeline job per service** on `main`, generated by the **Job DSL seed job**
([`.ci/jobs.groovy`](../.ci/jobs.groovy), see [`.ci/README-seed.md`](../.ci/README-seed.md)):
- New Item → `seed` (Freestyle) → SCM = the repo → Build step **"Process Job DSLs"** → `.ci/jobs.groovy` → Build.
- First run fails "script not approved" → Manage Jenkins → **In-process Script Approval** → approve →
  Build again → **13 jobs appear**.

### 8. Webhook (auto-trigger on push)
GitHub → repo → Settings → **Webhooks**:
- **Payload URL:** `http://<public-ip>:8080/github-webhook/`  ← plain Pipeline jobs use *this*
- **Content type:** `application/json`, **event:** push

### 9. First build of each job
Click **Build Now** once per job to push its first image (`ecom-repo:<service>-<sha>`). After that,
pushes that touch a service's folder build it automatically.

## Notes
- **Don't** run `chmod 666 /var/run/docker.sock` to grant docker access — it's insecure and resets on
  reboot. Use the docker **group** (Step 5).
- **`Could not find credentials matching ecr:ap-south-1:aws-ecr`** = the **Amazon ECR** plugin isn't
  installed (you have *AWS Credentials* but not *Amazon ECR*). Install it (Step 3).
- **First build of each job skips CI** — the `when { changeset "services/<svc>/**" }` filter has no
  previous build to diff against on the first run, so click **Build Now** once (manual = it runs anyway).
- Webhook must point at **`/github-webhook/`** — the older `/multibranch-webhook-trigger/invoke` path
  does **not** trigger plain Pipeline jobs.
- **Only on a small (1 GB) instance** — not needed on t3.medium:
  - Builds stall "waiting for executor" because the node goes offline on low `/tmp` →
    Manage Jenkins → Nodes → **Configure Monitors → Free Temp Space → "Don't mark agents temporarily offline."**
  - Docker Hub pulls time out mid-build → pre-pull base images once:
    `docker pull golang:1.23-alpine python:3.12-slim node:20-slim`.

## Verify
- `sudo -u jenkins docker ps` works.
- The `seed` build lists 13 generated jobs.
- A **Build Now** on `api-gateway` ends with `Login Succeeded` → `Pushed ...ecom-repo:api-gateway-<sha>`.
